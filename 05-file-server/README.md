 LAB WINDOWS SERVER : File Server (Serveur de fichiers) - Partage et Permissions


 Objectif du laboratoire

Ce laboratoire a pour objectif de configurer un serveur de fichiers (File Server) sous Windows Server afin de :

- Créer des dossiers partagés sur le réseau
- Gérer les permissions NTFS et de partage
- Contrôler l’accès des utilisateurs via Active Directory
- Tester l’accès depuis un poste client

 Prérequis

- Windows Server installé
- Active Directory configuré (domaine : lab.local)
- Poste client joint au domaine
- Deux utilisateurs créés dans AD
- Droits administrateur sur le serveur
